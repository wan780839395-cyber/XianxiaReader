# 阅读特色候选

2026-10-16，回应用户“阅读这一块还有什么可扩展的特色功能，当然要流畅”。本文是候选取舍，均不因写入文档而成为已实现或已授权全部开发的功能。

当前优先Build19整屏短空帧诊断/Build20候选保护。通过后沿M4独立切片推进：

| 候选 | 体验 | 顺序与性能边界 |
| --- | --- | --- |
| 自动慢滚 | 调到适合自己的速度；触摸即停，后台暂停，重开静止续读 | 最靠前，见READING_AUTOSCROLL_DRAFT.md；只移动当前有界视口，不逐帧解析正文、写库或发网络请求 |
| 回看不丢位置 | 临时查看前文、目录/搜索后，一键回到出发的具体行 | 先用有界完整Locator往返；保持现有主进度语义，须明确何时提交新进度，不能只保留百分比 |
| 续读接头 | 隔天打开可主动回看上次末尾几段，再回到原位置 | 优先原文短窗口，不生成AI剧情摘要，不自动跳动，不重写原阅读位置 |
| 克制的进度提示 | 菜单内显示本章剩余篇幅/预计时间，可选择隐藏全书进度 | 使用已有目录/索引和本地采样，低频更新；时间为估计，加载/停留时间不可当有效阅读速度 |
| 每本书的排版记忆 | 古风书用疏朗版式，长网文保留紧凑版式 | 后续M4，继承全局设置/局部覆盖要清楚；变更后仍保完整DOM锚点 |
| 离线听读/定时停止 | 用本机语音接续阅读，文字与朗读位置一致 | 较后候选，先核Readium capability、系统语音、锁屏/后台与耗电；不在当前切片铺开 |
| 无剧透人物/境界卡 | 长按名词查看当前位置已经揭示的信息 | M5候选；先建立可信canonical chapter与查询层过滤，不先读未来内容再遮挡，不提前铺世界观CRUD |

不优先堆叠粒子、持续动态背景或强制“仙气”动效。特色主要来自少打扰、可回退的位置操作和适合中文长篇的阅读节奏。必要动效短小、可关闭，并服从系统减少动态效果；实际手机流畅度单独验收。

## 已核参考

- [Readest官方阅读说明](https://www.readest.com/docs/reading)：核过自动滚动、章/全书进度、时间估计、居中呼出工具栏与脚注弹层。借鉴明确的交互目的；本项目慢滚拟重开静止，与其恢复运行策略不同。无需复制Web界面或引入服务。
- [KOReader官方用户手册](https://koreader.rocks/user_guide/)：核过Skim/回到前一位置及Book map的导航思路。取舍是优先便捷回看与安全返回，书图/全书缩略图矩阵不提前增加渲染成本。

以上优先级是本项目建议，不代表这些项目给出了本机性能或iOS兼容性结论；实施每一项仍须核对应API/精确版本与原生证据。
